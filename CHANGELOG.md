## [1.0.0] - 2026.11.03.1

### Added
- Biomimetic interspecific cross-breeding engine for AI Agent Skills.
- Functional genetic allele decomposition: Sensors, Cognition, Actuators, Invariants.
- FSM-driven combinatorial meiosis and boundary mutation fuzzer.
- Aleksakha Heterosis Gate enforcing hybrid vigor ($V(H) > \max(V_A, V_B)$).
- High-throughput CLI (`skill-breed breed`, `inspect`, `benchmark`).
- Zero-dependency pure Python stdlib architecture with PEP 517/621 packaging.
- Multi-AI tools compatibility layer (Kilo, Claude Code, Cursor, Windsurf).
